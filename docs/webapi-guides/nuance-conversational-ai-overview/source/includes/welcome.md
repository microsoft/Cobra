# Welcome to Nuance Conversational AI

Nuance Conversational AI is a secure, hosted platform for integrating sophisticated speech-to-text
(STT) and text-to-speech (TTS), as well as natural language understanding (NLU), 
capabilities in mobile and web applications.

Integrate these API commands with your natural language engine to leverage your investment in 
virtual assistant technologies across multiple channels and applications.
