# Speech Recognition

This command allows you to recognize speech using audio as input.

Audio must be sent as headerless binary payloads over the websocket connection. Each binary payload must be sent unfragmented with opcode 2 (0010) and FIN set to 1 (true) so that each buffer can be received and processed incrementally. Using fragmentation with continuation flags is discouraged as it can lead to exceeding the websocket buffer size and the websocket connection being closed.

## Speech Recognition-Cancel

The cancel directive allows one to cancel the speech recognition command in progress. This directive will only return a final result containing the canceling confirmation. Any partial data related to the running command will be discarded.

## Speech Recognition-Stop

The stop directive allows one to stop the speech recognition command in progress. This directive will return a final result that also contains any data related to the running command.
