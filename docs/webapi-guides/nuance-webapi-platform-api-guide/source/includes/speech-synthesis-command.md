# Speech Synthesis

This command allows you play audio using text as input.

<!--- Use HTML notation with and a unique id attribute, since the ### markdown notation will result in links conflicts in TOC -->
<h3 id="heading_speech_synthesis_parameters">Parameters</h3>


| Name     | Type       | Description                           |
|----------|------------|---------------------------------------|
| type | `String` | <p>The type of request.</p>_Allowed values: "command"_ |
| sessionId | `String` | <p>The server generated sessionId.</p> |
| metadata | `Object` | **optional** <p>A map of metadata associated with the command.</p>_Must be a json map_ |
| command | `Object` | <p>The command object.</p> |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "speechSynthesis"_ |
| <p class="param-1">id</p> | `String` | <p>The application step id (generated by the client application).</p> |
| <p class="param-1">parameters</p> | `Object` | <p>The parameter object.</p> |
| <p class="param-2">type</p> | `String` | **optional** <p>The type of data you provided. If none provided, the default will be taken from your customer config file. 'ssml' type is disabled by default. Please contact Nuance Technical Support Team to explicitly enable it.</p>_Default value: text_<br>_Allowed values: "text","ssml"_ |
| <p class="param-2">speechSynthesisRate</p> | `String` | **optional** <p>Speaking rate. Normal rate is 1.0.</p>_Default value: 1.0_<br>_Allowed values: 0.0 to 2.0_ |
| <p class="param-2">speechSynthesisTuningBundle</p> | `String` | **optional** <p>An optional parameter which allows the client to specify the text rule set and/or text dictionary files.</p> |
| <p class="param-2">speechSynthesisCodec</p> | `String` | **optional** <p>The codec to be used during speech synthesis. If none provided, the default will be taken from your customer config file.</p>_Allowed values: "pcm_16_8k","pcm_16_16k","pcm_16_22k","opus_nb","opus_wb","ulaw"_ |
| <p class="param-2">sensitivity</p> | `String` | **optional** <p>String that controls whether or not sensitive data for this command will be encrypted when logged to disk and reporting platform. Parameters description: &quot;open&quot; - non-encrypted, &quot;masked&quot; - replace everything with same character (Information will be lost forever), &quot;encrypted&quot; - data encrypted using a provided key</p>_Default value: masked_<br>_Allowed values: "encrypted","masked","open"_ |
| <p class="param-2">data</p> | `String` | <p>The text or ssml to synthesize . See below for examples with text or ssml.</p>_Size range: 64512_<br> |
| <p class="param-2">voice</p> | `String` | **optional** <p>The voice in which speech synthesis is to be done. If none provided, the default will be taken from your customer config file. Note this parameter works only with type &quot;text&quot;. To set a voice in ssml, see the example below.</p> |
| <p class="param-2">statistics</p> | `Boolean` | **optional** <p>Whether or not to return statistics on the command's performance.</p> |

> Request-Example with text:

```json

{
     "type": "command",
     "sessionId": "873315e5-d8bd-45a1-aa35-7cb47827e6ec",
     "command": {
         "name": "speechSynthesis",
         "id": "7",
         "parameters": {
             "type": "text",
             "data": "Good morning world."
         }
     }
}
```
> `json` - Request-Example with text (with optional parameters):

```json

{
     "type": "command",
     "sessionId": "873315e5-d8bd-45a1-aa35-7cb47827e6ec",
     "command": {
         "name": "speechSynthesis",
         "id": "7",
         "parameters": {
             "type": "text",
             "data": "Good morning world.",
             "voice": "Carol",
             "statistics": true
         }
     }
}
```
> Request-Example with ssml:

```json

{
     "type": "command",
     "sessionId": "873315e5-d8bd-45a1-aa35-7cb47827e6ec",
     "command": {
         "name": "speechSynthesis",
         "id": "7",
         "parameters": {
             "type": "ssml",
             "data": "&lt;?xml version=&#39;1.0&#39;?&gt;&lt;speak version=&#39;1.0&#39; xmlns=&#39;http://www.w3.org/2001/10/synthesis&#39; xmlns:xsi=&#39;http://www.w3.org/2001/XMLSchema-instance&#39; xsi:schemaLocation=&#39;http://www.w3.org/2001/10/synthesis http://www.w3.org/TR/speech-synthesis/synthesis.xsd&#39; xml:lang=&#39;en-us&#39;&gt;&lt;voice name=&#39;Tom&#39;&gt;This TTS is coming from an ssml document.&lt;/voice&gt;&lt;/speak&gt;"
         }
     }
}
```

## Speech Synthesis-Cancel

The cancel directive allows one to cancel the currently running speech synthesis command. This directive will only return a final result containing the canceling confirmation. Any partial data related to the running command will be discarded

| command | `Object` | <p>The command object.</p> |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "speechSynthesis"_ |

| directive | `Object` | <p>The directive object.</p> |

## Speech Synthesis-Stop

The stop directive allows one to stop the speech synthesis command in progress. This directive will return a final result that also contains any data related to the running command, and it will terminate the transmission of any new audio buffers.
