# Natural Language Understanding

## Interpretation

This command allows you to perform natural language understanding.

<!--- Use HTML notation with and a unique id attribute, since the ### markdown notation will result in links conflicts in TOC -->
<h3 id="heading_interpretation_parameters">Parameters</h3>


| Name     | Type       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|----------|------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| type | `String` | <p>The type of request.</p>_Allowed values: "command"_                                                                                                                                                                                                                                                                                                                                                                                              |
| sessionId | `String` | <p>The server generated sessionId.</p>                                                                                                                                                                                                                                                                                                                                                                                                              |
| metadata | `Object` | **optional** <p>A map of metadata associated with the command.</p>_Must be a json map_                                                                                                                                                                                                                                                                                                                                                              |
| command | `Object` | <p>The command object.</p>                                                                                                                                                                                                                                                                                                                                                                                                                          |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "interpretation"_                                                                                                                                                                                                                                                                                                                                                                                   |
| <p class="param-1">id</p> | `String` | <p>The application step id (generated by the client application).</p>                                                                                                                                                                                                                                                                                                                                                                               |
| <p class="param-1">parameters</p> | `Object` | <p>The parameter object.</p>                                                                                                                                                                                                                                                                                                                                                                                                                        |
| <p class="param-2">data</p> | `String` or `Object`| <p>The data on which to perform the interpretation.</p>                                                                                                                                                                                                                                                                                                                                                                                             |
| <p class="param-2">type</p> | `String` | **optional** <p>The type of the data.</p><p>_Default value: text/plain_<br>_Allowed values: **text/plain** (or **text**), **speechRecognitionVerboseResult***_</p>***speechRecognitionVerboseResult** is obtained from SpeechRecognition's response if speechRecognitionVerboseResult is set to true                                                                                                                                                |
| <p class="param-2">dialogModelApplicationVersion</p> | `String` | **optional** <p>The model version to be used.</p>                                                                                                                                                                                                                                                                                                                                                                                                   |
| <p class="param-2">sensitivity</p> | `String` | **optional** <p>String that controls whether or not sensitive data for this command will be encrypted when logged to disk and reporting platform. Parameters description: &quot;open&quot; - non-encrypted, &quot;masked&quot; - replace everything with same character (Information will be lost forever), &quot;encrypted&quot; - data encrypted using a provided key</p>_Default value: masked_<br>_Allowed values: "encrypted","masked","open"_ |
| <p class="param-2">activeDynamicVocabularySets</p> | `String[]` | **optional** <p>The list of dynamic vocabulary (defined by their ids) to activate for this interpretation command. NOTE: Do not upload more then 10 entries as this may have a noticeable performance degradation.</p>                                                                                                                                                                                                                              |
| <p class="param-2">statistics</p> | `Boolean` | **optional** <p>Whether or not to return statistics on the command's performance.</p>                                                                                                                                                                                                                                                                                                                                                               |
| <p class="param-2">language</p> | `String` | **optional** <p>Interpretation language to use.</p>                                                                                                                                                                                                                                                                                                                                                                                                 |
| <p class="param-2">maxInterpretations</p> | `Number` | **optional** <p>Maximum number of interpretations to be returned.</p>                                                                                                                                                                                                                                                                                                                                                                               |

> Request-Example:

```json

{
   "type":"command",
   "sessionId":"873315e5-d8bd-45a1-aa35-7cb47827e6ec",
   "command":{
      "name":"interpretation",
      "id":"1",
      "parameters":{
         "data":"Can I buy tulips and roses"
      }
   }
}
```
> Request Example (with optional parameters):

```json

{
   "type":"command",
   "sessionId":"873315e5-d8bd-45a1-aa35-7cb47827e6ec",
   "command":{
      "name":"interpretation",
      "id":"1",
      "parameters":{
         "data":"Can I buy tulips and roses",
         "type":"text/plain",
         "sensitivity":"masked",
         "activeDynamicVocabularySets":[
            "some_id1",
            "some_id2"
         ],
         "statistics":"true",
         "language":"eng-USA",
         "maxInterpretations": 8
      }
   }
}
```

<h3 id="heading_interpretation_success">Success</h3>


| Name     | Type       | Description                           |
|----------|------------|---------------------------------------|
| type | `String` | <p>The type of message received.</p>_Allowed values: "result"_ |
| sessionId | `String` | <p>The server generated sessionId.</p> |
| command | `Object` | <p>The command object.</p> |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "interpretation"_ |
| <p class="param-1">id</p> | `String` | <p>The application step id (generated by the client application).</p> |
| result | `Object` | <p>The result object.</p> |
| <p class="param-1">final</p> | `Boolean` | <p>True if it is the final result. False if it is an intermediate result.</p>_Allowed values: true_ |
| <p class="param-1">status</p> | `String` | <p>The state of the result.</p>_Allowed values: "success"_ |
| <p class="param-1">interpretations</p> | `Array` | <p>The interpretations. Each of them will have a confidence score. The best confidence score indicates the best result.</p> |
| <p class="param-2">concepts | `Array` | <p>Each interpretation will have an array of concepts. Concepts associate a value to a concept defined in the grammar.</p> |
| <p class="param-3">concept</p> | `String` | <p>The concept's name</p> |
| <p class="param-3">value</p> | `String` | <p>The concept's associated value for this interpretation</p> |
| <p class="param-3">literal</p> | `String` | <p>The literal in the input associated to this concept</p> |
| <p class="param-3">begin</p> | `Integer` | <p>The index at which the literal begins in the input</p> |
| <p class="param-3">end</p> | `Integer` | <p>The index at which the literal ends in the input</p> |
| <p class="param-2">confidence</p> | `Integer` | <p>The confidence of the interpretation</p>_Range: 0 to 100 (inclusive)_<br> |
| <p class="param-2">literal</p> | `String` | <p>The literal associated with the interpretation</p> |
| <p class="param-2">intent</p> | `String` | <p>The intent associated with the interpretation</p> |
| <p class="param-2">origin</p> | `String` | <p>The origin of the interpretation. (Grammar, SSM or Syntax)</p> |
| <p class="param-1">bestInterpretation</p> | `Object` | <p>The interpretation with the highest confidence score is extracted here for convenience.</p> |
