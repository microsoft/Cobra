#  Utilities

##  Get Resources

This command returns backend resources for an instance of WebApi

<!--- Use HTML notation with and a unique id attribute, since the ### markdown notation will result in links conflicts in TOC -->
<h3 id="heading_get_resources_parameters">Parameters</h3>


| Name     | Type       | Description                           |
|----------|------------|---------------------------------------|
| type | `String` | <p>The type of request.</p>_Allowed values: "command"_ |
| sessionId | `String` | <p>The server generated sessionId.</p> |
| metadata | `Object` | **optional** <p>A map of metadata associated with the command.</p>_Must be a json map_ |
| command | `Object` | <p>The command object.</p> |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "getResources"_ |
| <p class="param-1">id</p> | `String` | <p>The application step id (generated by the client application).</p> |

> Request Example:

```json
{
    "type":"command",
    "sessionId":"b6055028-640c-47c2-8b60-57d2ac896099",
    "command":{
        "name":"getResources",
        "id":"2"
    }
}
```

<h3 id="heading_get_resources_success">Success</h3>


| Name     | Type       | Description                           |
|----------|------------|---------------------------------------|
| type | `String` | <p>The type of message received.</p>_Allowed values: "result"_ |
| sessionId | `String` | <p>The server generated sessionId.</p> |
| command | `Object` | <p>The command object.</p> |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "getResources"_ |
| <p class="param-1">id</p> | `String` | <p>The application step id (generated by the client application).</p> |
| result | `Object` | <p>The result object.</p> |
| <p class="param-1">final</p> | `Boolean` | <p>True if it is the final result. False if it is an intermediate result.</p> |
| <p class="param-1">status</p> | `String` | <p>The state of the result. *</p>_Allowed values: "success"_ |
| <p class="param-1">resources</p> | `object` | <p>The Capabilities object</p> |
| <p class="param-2">speechRecognition</p> | `object` | <p>The SpeechRecognition resources object</p> |
| <p class="param-3">speechRecognitionCodec</p> | `string` | <p>The codec to be used during speech recognition</p>_Allowed values: "speechRecognitionCodec"_ |
| <p class="param-3">speechRecognitionEngine</p> | `string` | <p>The engine to be used during speech recognition</p>_Allowed values: "speechRecognitionEngine"_ |
| <p class="param-3">languagePack</p> | `string` | <p>The language pack to be used during speech recognition</p>_Allowed values: "languagePack"_ |
| <p class="param-2">speechSynthesis</p> | `object` | <p>The SpeechSynthesis resources object.</p> |
| <p class="param-3">vocalizer</p> | `string` | <p>Speech synthesis engine to use</p>_Allowed values: "vocalizer"_ |
| <p class="param-3">voices</p> | `Object[]` | <p>Array of voice objects.</p> |
| <p class="param-4">name</p> | `string` | <p>The name of the voice.</p>_Allowed values: "name"_ |
| <p class="param-4">voice</p> | `Object[]` | <p>Array of different codec/voice_model pairs</p> |
| <p class="param-5">codec</p> | `string` | <p>Audio codec of voice</p>_Allowed values: "codec"_ |
| <p class="param-5">voice_model</p> | `string` | <p>Voice model of voice</p>_Allowed values: "codec"_ |
