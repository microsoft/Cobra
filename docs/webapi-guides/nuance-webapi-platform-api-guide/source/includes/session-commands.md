#  Session

##  Start session

This command allows you to start a session. You must do so before calling any other commands offered in this API. This command requires user authentication. The authentication method is either via hashcode or JSON Web Token (JWT), depending on the server side configuration.

<h3 id="heading_start_session_parameters">Parameters</h3>

|----------|------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

If none provided, the default will be taken from your customer config file.</p>_Default value: adaptive_<br>_Allowed values: "legacy","adaptive"_                                                                              |
| <p class="param-2">beginNoiseSampleFrames</p> | `Integer` | **optional** <p>The number of frames taken at the start of recognition to assess the environment’s noise level. If none provided, the default will be taken from your customer config file.</p>_Default value: 10_<br>_Size range: 1..2<sup>31</sup>-1_<br>                                                 |
| <p class="param-2">voiceThreshold</p> | `Double` | **optional** <p>The amount of energy require for a frame to be considered 'voiced', as a factor of the background noise level. If none provided, the default will be taken from your customer config file.</p>_Default value: 4.0_<br>_Size range: -2<sup>63</sup>..2<sup>63</sup>-1_<br>                   |
| <p class="param-2">startOfSpeechVoicedFrames</p> | `Integer` | **optional** <p>Of the most recent startOfSpeechHistoryFrames, the number of 'voiced' frames required to assess that user has started speaking. If none provided, the default will be taken from your customer config file.</p>_Default value: 7_<br>_Size range: -2<sup>31</sup>..2<sup>31</sup>-1_<br>    |
| <p class="param-2">startOfSpeechHistoryFrames</p> | `Integer` | **optional** <p>The number of historical frames to use when assessing that the user has started speaking. If none provided, the default will be taken from your customer config file.</p>_Default value: 15_<br>_Size range: -2<sup>31</sup>..2<sup>31</sup>-1_<br>                                         |
| <p class="param-2">endOfSpeechVoicedFrames</p> | `Integer` | **optional** <p>Of the most recent endOfSpeechHistoryFrames, the number of 'voiced' frames which will indicate the user has not finished speaking. If none provided, the default will be taken from your customer config file.</p>_Default value: 5_<br>_Size range: -2<sup>31</sup>..2<sup>31</sup>-1_<br> |
| <p class="param-2">endOfSpeechHistoryFrames</p> | `Integer` | **optional** <p>The number of historical frames to use when assessing that the user has finished speaking. If none provided, the default will be taken from your customer config file.</p>_Default value: 50_<br>_Size range: -2<sup>31</sup>..2<sup>31</sup>-1_<br>                                        |
| <p class="param-2">considerNegativeRatios</p> | `Boolean` | **optional** <p>Whether or not to consider negative ratios when assessing speech activity. If none provided, the default will be taken from your customer config file.</p>_Default value: false_<br>                                                                                                        |
| <p class="param-2">speechSynthesisCodec</p> | `String` | **optional** <p>The codec to be used during speech synthesis.  If none provided, the default will be taken from your customer config file.</p>_Default value: pcm_16_8k_<br>_Allowed values: "pcm_16_8k","pcm_16_16k","pcm_16_22k","opus_nb","opus_wb","ulaw"_                                              |
| <p class="param-2">speechRecognitionCodec</p> | `String` | **optional** <p>The codec to be used during speech recognition.  If none provided, the default will be taken from your customer config file.</p>_Default value: pcm_16_8k_<br>_Allowed values: "pcm_16_8k","pcm_16_16k","opus_nb","opus_wb", "speex_16k", "ulaw", "alaw"_                                   |
| <p class="param-2">clientUserId</p> | `String` | **optional** <p>String defined by the client application to uniquely identify the user.</p>                                                                                                                                                                                                                 |
| <p class="param-2">clientDeviceId</p> | `String` | **optional** <p>String defined by the client application to uniquely identify the device. Should be letters, numbers, dash (-) and underscore (_).</p>                                                                                                                                                      |
| <p class="param-2">clientSessionId</p> | `String` | **optional** <p>String defined by the client application to identify its session.</p>                                                                                                                                                                                                                       |
| <p class="param-2">clientOsName</p> | `String` | **optional** <p>String defined by the client application to identify the OS it runs on.</p>                                                                                                                                                                                                                 |
| <p class="param-2">clientOsVersion</p> | `String` | **optional** <p>String defined by the client application to identify the OS it runs on.</p>                                                                                                                                                                                                                 |
| <p class="param-2">clientCarrier</p> | `String` | **optional** <p>String defined by the client application to identify the carrier (mobile devices or similar)</p>                                                                                                                                                                                            |
| <p class="param-2">clientPhoneModel</p> | `String` | **optional** <p>String defined by the client application to identify the device model (mobile devices or similar)</p>                                                                                                                                                                                       |
| <p class="param-2">clientDetails</p> | `Object` | **optional** <p>A JSON object as a placeholder for any details i.e client metadata or any other information. This information would be used for reporting purpose.</p>                                                                                                                                      |
| <p class="param-2">sensitivity</p> | `String` | **optional** <p>String that controls whether or not sensitive data for this session will be encrypted when logged to disk and reporting platform. Default &quot;masked&quot; (non-encrypted).</p>_Allowed values: "encrypted","masked","open"_                                                              |
| <p class="param-2">statistics</p> | `Boolean` | **optional** <p>Whether or not to return statistics on the command's performance.</p>                                                                                                                                                                                                                       |

   }
}
