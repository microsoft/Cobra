#  Vocabulary

##  Upload dynamic vocabulary

This command allows you to upload a dynamic vocabulary. Sending this message only loads the vocabulary, it doesn't activate it. It is still necessary to activate each message part by id in the speechRecognition command.<br/> ***Note:*** The uploaded vocabulary is only available for the active session.

<h3 id="heading_upload_dynamic_vocabulary_parameters">Parameters</h3>


| Name     | Type       | Description                                                                                                                                                                                                                                    |
|----------|------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| type | `String` | <p>The type of request.</p>_Allowed values: "command"_                                                                                                                                                                                         |
| sessionId | `String` | <p>The server generated sessionId.</p>                                                                                                                                                                                                         |
| metadata | `Object` | **optional** <p>A map of metadata associated with the command.</p>_Must be a json map_                                                                                                                                                         |
| command | `Object` | <p>The command object.</p>                                                                                                                                                                                                                     |
| <p class="param-1">name</p> | `String` | <p>The name of the command.</p>_Allowed values: "uploadDynamicVocabulary"_                                                                                                                                                                     |
| <p class="param-1">id</p> | `String` | <p>The application step id (generated by the client application).</p>                                                                                                                                                                          |
| <p class="param-1">parameters</p> | `Object` | <p>The parameter object.</p>                                                                                                                                                                                                                   |
| <p class="param-2">dynamicVocabularies</p> | `Object[]` | <p>The list of dynamic vocabularies.</p>                                                                                                                                                                                                       |
| <p class="param-3">id | `String` | <p>The id representing the dynamic vocabulary. Add this id in the speechRecognition command’s activeDynamicVocabularySets array to activate the vocabulary.</p>                                                                                |
| <p class="param-3">type | `String` | <p>The type of the vocabulary being defined.</p>_Allowed values: "application/x-nuance-wordset", "application/x-nuance-wordset-pkg", "application/x-nuance-builtin"_                                                                           |
| <p class="param-3">body | `Object` | <p>The body of the dynamic vocabulary wordset i.e. the vocabulary itself. For use with x-nuance-wordset.</p>                                                                                                                                   |
| <p class="param-4">vocabularyName</p> | `Object[]` | <p>This field key is dynamic, meaning it is directly the name of the wordset. Please refer to the example where this field is called &quot;place-name&quot; and &quot;hockey-team&quot;.</p>                                                   |
| <p class="param-5">literal</p> | `String` | <p>The literal name for this wordset.</p>                                                                                                                                                                                                      |
| <p class="param-5">spoken</p> | `String[]` | **optional** <p>The list of possible spoken words that represent the literal definition. This field is optional, if none provided, only the literal is used. The values for this field are ignored for interpretation.</p>                     |
| <p class="param-3">uri | `String` | <p>URI to the wordset for x-nuance-wordset-pkg. URIs may be limited to URNs (Mix), on-premise wordset URIs or hosted wordset URIs.</p>                                                                                                         |
| <p class="param-3">builtin | `String` | <p>The name of the builtin. For use with x-nuance-builtin.</p>                                                                                                                                                                                 |
| <p class="param-3">weight | `String` | <p>The weight associated with the vocabulary. For use with x-nuance-builtin.</p>                                                                                                                                                               |
| <p class="param-2">sensitivity</p> | `String` | **optional** <p>String that controls whether or not sensitive data for this command will be encrypted when logged to disk and reporting platform. Default &quot;masked&quot; (non-encrypted).</p>_Allowed values: "encrypted","masked","open"_ |
| <p class="param-2">statistics</p> | `Boolean` | **optional** <p>Whether or not to return statistics on the command's performance.</p>                                                                                                                                                          |

> Request-Example:

```json

{
   "type":"command",
   "sessionId":"873315e5-d8bd-45a1-aa35-7cb47827e6ec",
   "command":{
      "name":"uploadDynamicVocabulary",
      "id":"1",
      "parameters":{
         "dynamicVocabularies":[
            {
               "id":"some_id1",
               "type":"application/x-nuance-wordset",
               "body":{
                  "place-name":[
                     {
                        "literal":"Los Angeles",
                        "spoken":[
                           "l a",
                           "los angeles"
                        ]
                     },
                     {
                        "literal":"San Francisco"
                     }
                  ],
                  "hockey-team":[
                     {
                        "literal":"Montreal Canadiens",
                        "spoken":[
                           "montreal canadiens",
                           "habs"
                        ]
                     },
                     {
                        "literal":"Boston Bruins"
                     }
                  ]
               }
            }
         ]
      }
   }
}
```
