# API reference
> See [Reference topics](#reference-topics) to improve recognition using DLMs and wordsets

Krypton Plugin commands are based on a client-server protocol within a WebSocket connection. The commands are: 

- [CreateSession](#createsession): Start a new session in an idle Krypton Plugin connection. 
- [EndSession](#endsession): Terminate a live session. 
- [Load](#load): Load recognition objects (wordsets, domain LMs, and/or a semantic model) into the session.
- [Recognize](#recognize-and-interpret): Start a recognition turn to transcribe audio as text. 
- [StartRecognitionTimers](#startrecognitiontimers): Start timers for the current recognition turn.              
- [Stop](#stop):  Stop a Load or Recognize command. 
- [Audio data](#audio-data): Audio stream to be processed.  
- [EndOfInput](#endofinput):   Signal end of audio input. 

Commands generated by the Krypton Plugin in response to client commands are:

- [Response](#response): A response to each command. 
- [Event](#event): Information about events, including PartialResult and FinalResult, triggered during recognition.
- [Metrics](#metrics): Metrics included in responses and events. 

## Protocol version

The Krypton WebSocket Plugin exposes an API very close to that of the Krypton Websocket API version 1.0. Some commands, such as StatelessRecognize, Ping, GetInto, and 'GET metrics' are not supported. But it has the added functionality of being able to perform interpretation on recognition results.
