<h3 id="asr_codecs">Asr Codecs</h3>
 
| Name     | Type       |
|----------|------------|
| Opus |  "audio/opus;rate=16000" for 16 kHz Opus. <p>"audio/opus;rate=8000" for 8 kHz Opus. </p>|
| PCM|	"audio/L16;rate=16000" for 16kHz, 16-bit PCM. <p>"audio/L16;rate=8000" for 8kHz, 16-bit PCM.</p>|
| SPEEX	|"audio/x-speex;mode=wb" SPEEX is supported as a legacy format.|
  
<h3 id="tts_codecs">Tts Codecs</h3>
    
| Name     | Type       |
|----------|------------|
| Opus |  "audio/opus;rate=16000" for 16 kHz Opus. <p> "audio/opus;rate=8000" for 8 kHz Opus.</p>| 
| PCM|	"audio/L16;rate=22050" for 22 kHz, 16-bit PCM. "audio/L16;rate=16000" for 16kHz, 16-bit PCM. <p>"audio/L16;rate=8000" for 8kHz, 16-bit PCM.</p>|
| SPEEX	|"audio/x-speex;mode=wb" SPEEX is supported as a legacy format.|
